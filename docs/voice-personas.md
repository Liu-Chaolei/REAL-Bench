# Gaia2 caller voices

Gaia2 uses `gaia2_male` and `gaia2_female`. See [Gaia2 English runtime](gaia2-language-runtime.md#caller-profile) for caller behavior, voice overrides and provider-specific mappings.

The former multilingual voice-design workflow and its six language design files have been retired to the local archive. Existing provider voices are reused; this cleanup does not generate new voices.
