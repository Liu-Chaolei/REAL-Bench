# Gaia2 中立委托者实施记录

## 实现

新增 `src/tau2/user/gaia2_guidelines.py`，以 `gaia2-neutral-user-v1` 为版本标识，为文本、语音构造中立的人类任务委托者提示。

`runner/build.py` 通过实际环境域选择提示：

- 文本 `build_user()` 使用现有 `global_guidelines_override`。
- 语音 `build_voice_user()` 同时使用现有的指南和每轮角色提醒 override。
- `gaia2_hidden` 等复用 Gaia2 环境的任务集合自动使用该设定，不按模型、镜像或题号分支。

中立指南显式组合任务/未知信息/结束规则、语言指令、基础 verbosity、语法性别、拼写说明与已有领域说明，不使用完整 persona 插槽。因而不会从共享人设引入 customer、客服代表、找主管或故意含糊、假装遗忘等行为。

原 persona 对象仍用于声线及现有语音控制。没有修改共享语言包、题目数据、用户模拟器基类、动态追问、评分器、Agent 代码或镜像。下一次通过正常 builder 启动 Gaia2 评测即生效。

此次没有增加应用接入知识、默认权限或要求用户指导工具调用的规则。中立角色不保证被测 Agent 会正确执行任务。

## 开发阶段离线检查

`tests/test_multilingual/test_gaia2_user_guidelines.py` 两组检查共 6 个用例通过，耗时约 0.22 秒：

2. 对照 Gaia2 与 retail，确认原 persona 与传入语音配置没有被修改，选出的声学配置一致，retail 仍使用原客服提示。
