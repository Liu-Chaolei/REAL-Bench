# REAL-Bench 指标迁移：实现与验证入口

本方案按整通对话意图评测实现：实际送达用户要求按顺序合为一份，实际后台任务消息合为另一份，再独立抽取和双向原文核对。阶段边界保留为来源与时间依据，不以逐阶段首次传递分数的平均值作为主分。

实现包含独立证据契约、公共环境和媒体采集、可选后台观察、Gaia2 四项执行适配、八项 REAL 语音指标，以及运行后自动评分、离线重评、缓存、汇总和终端展示。新增成绩与原 τ reward 并列。

使用方式、接口、版本和限制见 [REAL-derived diagnostics](real-metrics.md)。默认配置见 [examples/real-metrics.yaml](../examples/real-metrics.yaml)。迁移核心的源版本及文件哈希保存在 `src/tau2/diagnostics/SOURCE.json`。

验证按以下顺序执行：

1. REAL 原有计分与波形样例在 τ 内独立重放，验证算法一致性。
2. 连续请求、未送达内容、生成实体绑定、中间效果、已失败的原 evaluator、真实播放证据及完整性检查。
3. 全部 800 个任务的业务工具、非空参数和效果处理器覆盖扫描。
4. 使用原生应用参考执行和严格重放，保留语义未知项；通过原命令生成运行时 seal。
5. 核心、voice 和提供方离线回归，及固定真实语音样本验收。

每次验收的源代码、配置、原始任务与结果应保留在独立目录。实现测试通过不代表真实模型能力或 GT 的人工语义审核通过。
