# Qwen persistent task 实现与真实验证结果

当前代码已接通真实 Qwen 事件、任务身份绑定、状态投影、语音边界调度、原生操作归属、回复窗口、独立评分和确定性 replay。

十个候选均执行了真实验证；其中八题形成完整测量，四题原生管理行为通过、四题按证据得到未通过结果。两道失败查询缺少可验收的真实 failed 场景，继续保留 draft。因此“十题全部验收”仍未达到，未扩展到 100 题。

原生管理分与原始/派生 Gaia2 业务分分别记录。只有显式启用组合且 reward basis 包含 PERSISTENT_TASK 时才合成；取消题的原生管理分为 1.0，不因先前业务约束失败而被隐式归零。

完整测量表示请求实际投递、证据可追溯且可评分，不表示被测 Agent 必须通过该题。未触发、身份歧义与缺失证据均没有被当作模型答错或默认满分。姓名一例的判断基于录音转写，原始音频与 judge 判决保留，未用 Gateway 字幕或后端文本替代实际播出的回复。

运行配置、构建与复验命令见 [实现和运行说明](qwen-persistent-validation.md)。历史 qpt 报告与 evidence/config hashes 在 [native manifest](../data/tau2/domains/gaia2/manifest.json)；每次失败和每版关联题定义均保留。
