# Gaia2 Dynamic Hidden-Intent

The hidden-intent package is an independent 100-task task set derived from the
frozen pre-variant Gaia2 population. It does not modify the canonical Gaia2
tasks or manifest.

The package contains 20 source tasks from each original Gaia2 category. Each
task keeps the original snapshot, reference operations and final-state checks.
The caller-facing text masks one or more details. The authoring manifest records
51 tasks with one hidden item, 35 with two, and 14 with three.

The task set can be inspected through the Gaia2 CLI:

```bash
UV_FROZEN=1 tau2 run --benchmark none --domain gaia2 \
  --task-set-name gaia2_hidden --task-split-name hidden_intent \
  --language en --num-trials 1 --num-tasks 5 --dry-run
```

The source selection, hidden requirements and graph records are stored under
`data/tau2/domains/gaia2_hidden/`. The package is currently an authoring draft.
The generated requests are mechanically masked and require semantic and
naturalness review. The runtime mechanism is exercised first by the separate
five-task trial below, whose public diagnostic is Hidden Ask Rate.

## Two-task check

| Source task | Visible placeholder | Hidden value | Specific question | Observed result |
| --- | --- | --- | --- | --- |
| `0348`, Moscow properties | `my chosen price limit` | `$3,000` | What price threshold should I use for the Moscow properties? | Releases the amount node |
| `0149`, group chat | `a group name I will provide` | `Email List` | What should I name the new group chat? | Releases the title node |

The matcher uses the declared aliases and field descriptions. Broad requests
for more details remain unreleased; a direct question about the declared field
releases it for the User Simulator's next normal LLM response.

The table is a lightweight mechanism check; it does not add a separate reply
quality score or a post-hoc protection judge.

The current task files are generated by:

```bash
UV_FROZEN=1 .venv/bin/python scripts/generate_gaia2_hidden.py
```

The mechanism can be smoke-tested with a small selection from the 100-task set:

```bash
UV_FROZEN=1 tau2 run --domain gaia2 \
  --task-set-name gaia2_hidden --task-split-name hidden_intent \
  --language en --num-trials 1 --num-tasks 5
```

Its private goal graphs are passed only to the User Simulator. The simulator
uses the existing LLM response path after a programmatic field match releases a
hidden value; it does not use a separate fixed answer path.

The hidden package hides values only in the initial stage. Later stage goals and source
requests remain owned by the existing Gaia2 Dynamic Follow Up path; they are not
added to the hidden-intent graph.

Generation is deterministic from the frozen 800-task archive and writes only
the independent hidden-intent package.
